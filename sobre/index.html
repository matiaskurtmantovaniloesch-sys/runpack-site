A Run Pack

Tecnologia de empacotamento para quem vive a safra

Fabricamos máquinas de empacotamento para hortifrúti pensadas para a rotina real de um packing house: alto volume, troca rápida de formato e fruta intacta do início ao fim.

Missão

Máquina para produzir, não para explicar

Quem decide a compra de uma máquina de empacotamento quer ver produtividade real: caixas por hora, troca de formato e assistência quando precisar. É para essa pessoa que a Run Pack projeta.
